Glossary: ops seams

Terms that decide where work runs in this bot. Stick to these meanings in lessons.

Webhook (HTTP process)
FastAPI app that accepts inbound CRM/WhatsApp events. Must return quickly (202). File: client_webhook.py.
Worker (RQ process)
Separate process that dequeues jobs and runs slow work (CRM, Gemini, dispose, reply). File: client_worker.py → client_tasks.handle_client_message.
Redis
In-memory store used as RQ broker and for session/dedupe/rate-limit/locks. Not the CRM database.
RQ (Redis Queue)
Python library: enqueue a function name + args; a worker executes it later. Backed by Redis.
Enqueue
Put a job on the queue. Webhook enqueues; does not run the handler itself.
Service (Compose)
One container definition in compose.yaml (e.g. redis, client-webhook, client-worker).
Service DNS
On Compose’s default network, containers reach each other by service name (redis://redis:6379).
Profile
Compose switch that includes optional services (client, mock). Production client path uses profile client.
Dedupe key
client:seen:{message_id} — Redis key so redelivered messages are not processed twice.
Queue name
CLIENT_QUEUE_NAME — webhook and worker must share the same name or jobs sit forever.
